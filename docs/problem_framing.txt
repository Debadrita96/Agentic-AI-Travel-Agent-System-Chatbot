# Problem Framing

## User Persona
The primary user is a travel customer seeking assistance with trip planning, budgeting, and understanding travel policies such as refunds or baggage rules.

## Workflow
User enters a query → AI agent processes → retrieves knowledge if needed → generates response → ensures safety compliance.

## Problem Statement
Traditional customer support systems are slow, inconsistent, and require manual intervention. Users often face difficulty in:
- planning trips efficiently
- understanding policies
- getting quick responses

## Inputs & Outputs
- Input: natural language travel query
- Output: structured, safe, and helpful response

## Constraints
- No execution of real-world actions (e.g., booking, payments)
- No storage of sensitive user data
- Must avoid hallucination

## Success Criteria
- relevant and useful responses
- safe handling of risky queries
- ability to provide structured travel guidance

## Failure Cases
- vague queries → generic response
- missing knowledge → fallback response
- unsafe request → refusal required
