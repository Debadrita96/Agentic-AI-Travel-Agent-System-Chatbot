## 📌 Overview
This project implements an Agentic AI system that assists users in travel-related workflows such as itinerary planning, policy queries, and budget estimation.

The system evolves from a rule-based baseline to a fully functional AI agent incorporating:
- LLM reasoning
- Retrieval-Augmented Generation (RAG)
- Tool usage
- Safety guardrails
- Evaluation pipeline

---

## 🧠 Features
- Baseline vs LLM comparison
- Knowledge-based responses using RAG
- Travel planning & budgeting
- Safety-first design (no transactions)
- Deployed via Streamlit
